# Карточки товаров для Wildberries: примеры работ

**Смотреть галерею:** https://skufik2007.github.io/wb-cards-portfolio/

Инфографика 900x1200 (формат 3:4) и тексты для карточек WB. В каждой карточке:

- 3 слайда: обложка, преимущества, размеры / состав / инструкция;
- SEO-название до 60 символов;
- продающее описание с ключевыми запросами;
- характеристики в формате личного кабинета WB.

## Как устроено

- `js/data.js`: тексты и параметры карточек;
- `js/templates.js`: пустые шаблоны;
- `js/art.js`: векторные иллюстрации товаров;
- `js/render.js`, `css/slides.css`: макеты слайдов;
- `node export.js`: выгрузка всех слайдов в PNG через Microsoft Edge (нужен локальный сервер на порту 8765, отдающий родительскую папку).

Товары и бренды в примерах вымышлены, иллюстрации нарисованы специально для портфолио.
